# Air Conflicts (2006) Widescreen Fix

Widescreen and ultrawide resolution fix for **Air Conflicts** (2006), also known as *Air Conflicts: Air Battles of World War II* (PC). Runtime ASI plugin, no executable modification.

**[Download latest release](https://github.com/EagleWatchTK/AirConflicts.WidescreenFix/releases)**

## Features
- Custom resolution via `WidescreenFix.ini`
- No executable modification

## Compatibility
- Tested on: original retail version, **unpatched**
- Patched versions (1.03, 1.043): untested. Reports welcome in Issues.

## Installation
1. Install [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader).
2. Copy `AirConflicts.WidescreenFix.asi` and `WidescreenFix.ini` into the game folder.
3. Set your resolution in `WidescreenFix.ini`.
4. In the game launcher, select **1600×1200**. The fix replaces it with your resolution.
5. Launch the game.
