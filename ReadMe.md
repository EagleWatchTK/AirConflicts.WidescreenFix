# Air Conflicts (2006) / Air Conflicts: Air Battles of World War II Widescreen Fix

A runtime widescreen fix for the original **Air Conflicts** using Ultimate ASI Loader.

## Features

- Custom resolution via `WidescreenFix.ini`
- No executable modification required
- Runtime memory patch
- Original retail executable support

## Installation

1. Install Ultimate ASI Loader.
2. Copy `AirConflicts.WidescreenFix.asi` into the game directory.
3. Copy `WidescreenFix.ini` into the game directory.
4. Edit `WidescreenFix.ini` with your desired resolution.
5. In the launcher, select **1600×1200**.
6. Launch the game.

## Configuration

```ini
[MAIN]
Width=1920
Height=1080
```
